# BetterFy compact identity

These founder-authored assets are the approved compact BetterFy symbol family.
They complement the BetterFy text wordmark; they do not replace the wordmark
inside the application interface.

| Asset | Approved use |
| --- | --- |
| `betterfy-symbol-dark.jpg` | Telegram bot, application/package icon, GitHub README and social preview |
| `betterfy-symbol-light.jpg` | Telegram channel and community chat |
| `betterfy-symbol-dark-on-light.jpg` | Auxiliary export when a light safety field is required |
| `betterfy-github-social.png` | 1280×640 GitHub repository social preview |

`src-tauri/icons/icon-source.png` is the lossless application-icon master made
from the dark variant. Run `npm run icon:generate` to regenerate the Tauri icon
pack. Do not apply an extra mask, border, wordmark or color shift to the symbol.

The application UI continues to use the existing BetterFy text wordmark until
a separate interface change is explicitly approved.
