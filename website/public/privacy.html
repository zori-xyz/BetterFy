Приватность

Это простая сводка того, что делают сайт, сервис входа и приложение сейчас. Это не юридически выверенный документ: он изменится, когда BetterFy выйдет из раннего доступа, и мы поправим эту страницу вместе с ним.

Сайт

  • Без аналитики, рекламных пикселей и cookie. Шрифты и картинки отдаются с самого сайта.
  • Сайт лежит на GitHub Pages, поэтому GitHub, как любой веб-сервер, видит IP-адрес и заголовки запроса.
  • В браузере сохраняются только язык и тема (localStorage). Если ты вошёл, сессия лежит в sessionStorage и исчезает вместе с вкладкой.

Запросы к другим сервисам

  • Когда ты открываешь окно загрузки, сайт спрашивает у api.github.com список релизов. Сам установщик скачивается с GitHub Releases.
  • При входе сайт обращается к сервису авторизации BetterFy на Cloudflare Workers. Вход через Telegram проходит через Telegram.

Что хранит сервис входа

  • Telegram: числовой идентификатор, имя, никнейм и идентификатор файла аватара. Сам аватар мы не храним, он проксируется при показе.
  • BetterFy ID: никнейм, пароль только в виде солёного хэша, почта только в виде хэша с ключом и маски для подсказки. Открытый адрес почты не сохраняется.
  • Сессии: случайный идентификатор, тип клиента (сайт, Windows или неизвестно) и срок действия. IP-адреса, user-agent и названия устройств в сессиях не хранятся.
  • Защита от перебора: лимиты запросов считаются по хэшу адреса с ключом.
  • Доступ: уровень (ранний доступ или Premium) и, если ты платил Telegram Stars, номер заказа, сумма и валюта. Платёж проводит Telegram.
  • Сессия сайта живёт двенадцать часов, одноразовые коды действуют десять минут.

Приложение для Windows

  • Читает файлы Steam и Dota 2 на твоём компьютере и пишет только те, что нужны для установки и отката. Журнал и резервные копии лежат локально.
  • Данные для входа хранятся в Диспетчере учётных данных Windows.
  • Диагностику и журнал мы получаем только если ты сам их отправил в поддержку.

Удаление и сроки хранения

Кнопки удаления аккаунта в интерфейсе пока нет, и срок хранения данных ещё не определён: это в плане работ. Запрос на удаление можно отправить в поддержку в Telegram. Сейчас такие запросы разбираются вручную, срок ответа мы не гарантируем.

Чего не присылать

Коды входа, токены, ссылки подтверждения, Steam ID и пути, в которых есть твоё имя. Если что-то из этого уже попало в открытый разговор, напиши об этом без повторения значения.

Privacy

This is a plain summary of what the site, the sign-in service and the app do today. It is not a lawyer-reviewed document. It will change when BetterFy leaves Early Access, and this page will change with it.

The website

  • No analytics, advertising pixels or cookies. Fonts and images are served from the site itself.
  • The site is hosted on GitHub Pages, so GitHub, like any web server, sees your IP address and request headers.
  • The browser keeps only your language and theme (localStorage). If you sign in, the session lives in sessionStorage and disappears with the tab.

Requests to other services

  • When you open the download dialog, the site asks api.github.com for the list of releases. The installer itself downloads from GitHub Releases.
  • When you sign in, the site talks to the BetterFy auth service on Cloudflare Workers. Telegram sign-in goes through Telegram.

What the sign-in service stores

  • Telegram: the numeric ID, display name, username and an avatar file ID. We do not keep the avatar itself; it is proxied when shown.
  • BetterFy ID: a username, the password only as a salted hash, and the email only as a keyed hash plus a masked hint. The plain email address is not stored.
  • Sessions: a random ID, the client kind (web, Windows or unknown) and an expiry. Sessions do not store IP addresses, user agents or device names.
  • Brute-force protection: rate limits are counted on a keyed hash of the requester address.
  • Access: your tier (Early Access or Premium) and, if you paid with Telegram Stars, the order ID, amount and currency. Telegram processes the payment.
  • A website session lasts twelve hours and one-time codes are valid for ten minutes.

The Windows app

  • It reads Steam and Dota 2 files on your computer and writes only the ones needed to install and restore. The journal and backups stay local.
  • Sign-in credentials are kept in Windows Credential Manager.
  • We only receive diagnostics and the journal if you send them to support yourself.

Deletion and retention

There is no account deletion button yet, and a retention period is not defined yet; both are on the work plan. You can send a deletion request to the Telegram support. Such requests are handled by hand for now and we do not guarantee a response time.

What not to send

Sign-in codes, tokens, confirmation links, Steam IDs, and paths that contain your name. If one of them has already leaked into a public conversation, say so without repeating the value.
